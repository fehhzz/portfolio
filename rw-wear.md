# RW Wear — Digital Storefront

[← Portfolio](README.md)

## Problem

Make a clothing catalog easy to browse and connect product interest to a contact-based purchase journey.

## Implementation

The storefront uses HTML, CSS and JavaScript with product search, category/filter navigation and product-detail interactions. Supabase supports catalog/settings data and an administration interface. The purchase flow leads to WhatsApp.

**Stack:** HTML, CSS, JavaScript and Supabase.

## Technical decisions

- A framework-free frontend keeps the catalog interface straightforward.
- Product navigation and detail views help customers evaluate items before making contact.
- Catalog administration is separate from the public storefront.

## Scope

The current source disables the e-commerce checkout flag. This project is presented as a catalog and contact-based storefront, not as a completed payment or order-processing platform. Production Supabase configuration and metadata require review before source publication.

The implementation identifies the brand as **RW Wear**; the original repository is named `RVWear`. That existing identifier is preserved to avoid changing deployment integration without verification.
